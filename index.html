HWP

HWP 또는 HWPX 파일을 여기에 놓으세요

일반 HWP 5.0은 WASM 엔진으로, HWPX는 XML 편집 엔진으로 브라우저 안에서 처리합니다.

  • .hwp: 페이지 렌더링 + 문단/표 셀 텍스트 편집 + HWP 다시 저장
  • .hwpx: 원본 XML 서식 기반 직접 편집 + HWPX 다시 저장
  • 문서 파일 자체는 서버에 업로드하지 않고 사용자의 브라우저 메모리에서 처리합니다.
  • HWP에서는 수정할 문단 또는 표 셀을 더블클릭하면 텍스트 편집창이 열립니다.
